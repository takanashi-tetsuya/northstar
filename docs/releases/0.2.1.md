Northstar is developed collaboratively by humans and AI.

Northstar 0.2.1 fixes a database deadlock when several sessions of the same
account resume concurrently. Privacy-list selection now retains the shared
authorization lock, and list deletion remains serialized with active selections.
WebSocket connections also use smaller initial read buffers to reduce memory
use with many connected clients; message-size limits are unchanged.

Scheduled validation now uses bounded authentication concurrency, preserves
SASL2 device identities during resumption, and checks exact duplicate cluster
ACKs. Parser fuzzing uses the same pinned nightly in CI and WSL.
MIX stress tests admit credential setup on half the available CPUs, capped at
four operations, to reduce preparation time for the test matrices.
Source CI now runs load, cluster fault and fuzz tests on every PR and main
commit. Regular listener checks use 5×50, periodic checks use 20×50, and
100×50 endurance runs are selected manually.

The signed v0.2.0 candidate remains unchanged. These packages and container
images are built and verified from the v0.2.1 source tag.

Supported downloads are Windows x64, Linux x64 and Docker linux/amd64. Linux
and Docker are the production baseline; Windows is for development and
evaluation. Use the complete archive for the Web client, administration UI,
Swagger UI, configuration examples and license notices. Raw executables need
those matching files beside them.

Read `docs/INSTALL.md` inside the archive before startup. PostgreSQL 15 or newer
is required. Existing installations must follow the matching migration and
database-role instructions; some migrations require stopped writers. Keep a
verified backup before an upgrade.

This remains a pre-1.0 release. The independent microservices are prototypes,
and Redis clustering retains the qualifications documented in the known-issues
register. The release checks verify the packaged artifact in isolated fixtures;
operators still qualify their production configuration and restore procedures.
