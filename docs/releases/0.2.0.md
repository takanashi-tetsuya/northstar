Northstar is developed collaboratively by humans and AI.

Northstar 0.2.0 brings complete Windows and Linux packages, Docker images, and
improvements to session recovery and deployment. The packages include the XMPP
server, browser client, administration interface and configuration examples.

## Changes

- Core and maintenance tasks can run in separate processes over shared PostgreSQL.
- Concurrent session resumption no longer deadlocks when several devices use
  the same account. WebSocket connections also use less memory while idle.
- Database migrations and server traffic use separate roles; management endpoints
  have their own listener.
- Backup tools sign and encrypt backups and validate them before restore.

See the [full changelog](https://github.com/takanashi-tetsuya/northstar/blob/v0.2.0/changelog/v0.2.md)
for protocol, administration and reliability changes.

## Downloads

| Platform | Package |
|---|---|
| Linux x64 | `northstar-0.2.0-linux-amd64.tar.gz` |
| Windows x64 | `northstar-0.2.0-windows-amd64.zip` |
| Docker linux/amd64 | `ghcr.io/takanashi-tetsuya/northstar:0.2.0` |

Use the complete archive for a native installation. The standalone executables
also need the matching Web assets, configuration and license files beside them.
Docker deployments include separate backup and database-grant images; their
exact references are listed in `IMAGE_DIGESTS`.

## Installation and upgrades

PostgreSQL 15 or newer is required. Start with the
[installation guide](https://github.com/takanashi-tetsuya/northstar/blob/v0.2.0/docs/INSTALL.md).
For an existing installation, back up the database and follow the migration
and database-role steps in the
[operations guide](https://github.com/takanashi-tetsuya/northstar/blob/v0.2.0/docs/PRODUCTION_OPERATIONS.md).
Some migrations require stopping writers.

Linux and Docker are the supported production targets. Windows is for development
and evaluation. The distributed services remain prototypes, and Redis clustering
is experimental. Review the
[known limitations](https://github.com/takanashi-tetsuya/northstar/blob/v0.2.0/docs/KNOWN_ISSUES.md)
and [protocol support](https://github.com/takanashi-tetsuya/northstar/blob/v0.2.0/XEP_MATRIX.md)
before deployment.
