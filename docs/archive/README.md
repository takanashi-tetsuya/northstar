# Historical documentation archive

Files in this directory are immutable point-in-time records of earlier
development, handoff and validation work. They can explain why a design changed,
but they must not be used to decide current protocol support, security posture,
release readiness or remaining work.

Current authority order:

1. source code and migrations;
2. [`XEP_MATRIX.md`](../../XEP_MATRIX.md);
3. [`docs/KNOWN_ISSUES.md`](../KNOWN_ISSUES.md);
4. [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md) and
   [`docs/PRODUCTION_OPERATIONS.md`](../PRODUCTION_OPERATIONS.md);
5. [`docs/TRACEABILITY.md`](../TRACEABILITY.md).

Archived files retain their original names so old links and audit references
can be repaired unambiguously. When quoting them, include their recorded date
and version and check every conclusion against the current authority set.
