Northstar 0.2.0 adds separate core and maintenance processes over shared
PostgreSQL, strengthens runtime supervision and database authority boundaries,
and provides complete native packages plus three Linux container images.

Supported downloads are Windows x64, Linux x64 and Docker linux/amd64. Linux
and Docker are the production baseline; Windows is for development and
evaluation. Use the complete archive for the Web client, administration UI,
Swagger UI, configuration examples and license notices. Raw executables need
those matching files beside them.

Read `docs/INSTALL.md` inside the archive before startup. PostgreSQL 15 or newer
is required. Existing installations must follow the matching migration and
database-role instructions; some migrations require stopped writers. Keep a
verified backup before an upgrade.

This remains a pre-1.0 release. The independent microservices are prototypes,
and Redis clustering retains the qualifications documented in the known-issues
register. The release checks verify the packaged artifact in isolated fixtures;
operators still qualify their production configuration and restore procedures.
